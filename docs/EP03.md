This video provides a step-by-step guide on setting up a professional development environment for a *Retrieval Augmented Generation (RAG)* project. Below is the detailed breakdown:

## 1. Setting up Version Control (0:03-2:47)

*   **GitHub Repository:** Create a repository on *GitHub* to store the project code.
*   **Git Client:** Install *Git* on your machine (official website for Windows, `apt install git` for Linux).
*   **Verify Git:** Use `git --version` in the terminal to confirm installation.
*   **Cloning:** Copy the repo link from *GitHub*, then use `git clone <link>` in the terminal.
*   **Authentication:** If prompted, generate a personal access token from *GitHub* settings (under Developer settings \> Personal access tokens) to act as your password.

## 2. Setting up the Editor and Python Environment (2:47-7:28)

*   **Editor:** Install *Visual Studio Code*.
*   **Anaconda/Miniconda:** Install *Miniconda* to manage Python environments.
    *   *Tip:* During installation on Windows, ensure you select the option to add it to your PATH so it works in any terminal.
*   **Environment Creation:** Open the project folder in *VS Code*, then create a specific environment for the project:
    *   `conda create -n mini_rag_app python=3.8`
    *   `conda activate mini_rag_app`

## 3. Configuring WSL (Windows Subsystem for Linux) (7:28-13:34)

*   **Purpose:** Running code in a Linux environment is recommended for production consistency.
*   **Requirements:** Ensure your Windows version is 2004 or higher.
*   **Installation:** Run `wsl --install` in *PowerShell* (as administrator).
*   **Ubuntu:** Search for *Ubuntu* in the Start menu, launch it, and set up your username/password.
*   **Integration:** Open your project in *VS Code*, and use the terminal within *VS Code* to select the *Ubuntu (WSL)* terminal type instead of the default Windows prompt.

## 4. Setting up Miniconda on Linux/WSL (13:34-18:05)

*   **Download:** Download the Linux installer script via the terminal using `wget` followed by the link for the 64-bit installer.
*   **Installation:**
    *   Make it executable: `chmod +x <filename>`
    *   Run it: `./<filename>`
*   **Finalize:** Follow the prompts (type `yes` to accept). If asked to initialize the path, answer `yes`.
*   **Activation:** Refresh the terminal (or run `source ~/.bashrc`) and repeat the conda environment creation steps (`conda create` and `conda activate`) within the *WSL/Ubuntu* terminal.

## 5. Troubleshooting (18:05-18:37)

*   If `conda activate` fails to find the environment, use `conda info --envs` to list environments and activate using the full path to the environment directory.
