## Project Overview: mini-RAG

This repository contains the source code for the **mini-RAG** project, a series dedicated to building an open-source **Retrieval Augmented Generation (RAG)** application [link](https://www.youtube.com/playlist?list=PLvLvlVqNQGHCUR2p0b8a0QpVjDUg50wQj).

### Mission & Goals

The primary objective of this project is to bridge the gap between experimental *Jupyter Notebooks* and production-ready applications. Many data science and machine learning projects struggle in production environments due to a lack of software engineering best practices; this series aims to provide developers with the skills to package their models into functional, deliverable web applications.

### Key Features

*   **Production-Ready Architecture:** Transitioning from simple scripts to scalable web applications using Python frameworks.
*   **RAG Implementation:** Demonstrating how to use large language models to answer user queries based on specific provided documentation.
*   **Educational Template:** This project serves as a template for others to learn from and build upon. Contributions are highly encouraged, with the expectation that contributors provide tutorials or explanations (via pull requests) for their additions to maintain the project's educational value.

### Repository Structure

*   **`main` Branch:** Always contains the most current, stable version of the application.
*   **Checkpointing:** The repository uses git tags or branches corresponding to each tutorial video, allowing you to easily navigate to the exact state of the code demonstrated in any specific episode.

This project assumes the audience may have limited experience with web development, making it an ideal starting point for those looking to professionalize their data science workflows.
