In this video, the creator continues building a **mini-RAG** project by organizing the codebase and managing environment variables. Here is the step-by-step process:

### 1. Refactoring Routes

To keep `main.py` clean and scalable, the creator separates the API routes into a dedicated directory:

*   **Create directory:** A `routes` directory is created (1:44).

*   **Initialization:** An `__init__.py` file is added to the `routes` directory to allow Python to treat it as a module (2:12-2:30).

*   **Create base routes:** A new file `base.py` is created inside the `routes` directory to house initial endpoints (3:00-3:06).

*   **Setup API Router:** Inside `base.py`, the creator replaces the `FastAPI` instance with `APIRouter` (4:50-5:03):
    python
    from fastapi import APIRouter
    base_router = APIRouter()

    @base_router.get("/")
    async def welcome():
    return {"message": "Hello"}

*   **Include router in main.py:** The `main.py` file is updated to import and include the new router (6:35-7:15):
    python
    from routes.base import base_router
    app.include_router(base_router)

### 2. Organizing Endpoints (Prefix & Tags)

*   **Prefix:** The creator adds a prefix to `APIRouter` so all routes under it require a specific path, e.g., `/api/v1` (8:30-9:16).
*   **Tags:** A tag is added to the router for better organization in the Swagger UI (9:20-9:51).
    python
    base_router = APIRouter(prefix="/api/v1", tags=["api-version"])

### 3. Environment Variables Configuration

*   **Install python-dotenv:** The creator installs the library to manage environment variables (10:38-10:55):
    `pip install python-dotenv`
*   **Configure main.py:** The `load_dotenv()` function is added to `main.py` to ensure all variables from a `.env` file are loaded into the system (11:12-12:48).
